Todo o experimento em cinco passos

As cinco etapas podem ser abertas para acompanhar o projeto sem conhecimento prévio de aprendizado de máquina.
1 O que o projeto faz

Ele ensina um modelo a reconstruir partes escondidas de imagens. O tema é masked modeling: esconder uma parte da entrada e usá-la como exercício de previsão.

O modelo principal é o MAE, sigla de Masked Autoencoder. Neste repositório, ela não significa erro absoluto médio.

2 Como os dados são preparados

O projeto obtém o CIFAR-10, verifica seu MD5 e escolhe imagens equilibradas entre 10 classes.

São guardadas 5.000 imagens para treino, 1.000 para validação e 1.000 para teste. Cada imagem tem 32 por 32 pixels.

3 O que acontece durante o treino

Cada imagem vira 16 pedaços quadrados, chamados patches. Uma condição esconde 8 pedaços e outra esconde 12.

O encoder interpreta apenas os pedaços visíveis. O decoder tenta reconstruir os pixels escondidos. O erro é medido por MSE, a média das diferenças quadráticas.

O treino exige uma GPU NVIDIA com CUDA e não muda para CPU se ela estiver ausente.

4 Onde aparecem as evidências

resultados/metricas.csv guarda as medidas. curva_perda.png mostra a mudança do erro. reconstrucoes.png compara imagens originais, cobertas e reconstruídas.

Os slides mostram também um experimento complementar público. Ele é separado dos números medidos pelo código deste repositório.

5 Como executar e o que observar

O README descreve a instalação com uv sync --no-dev e a execução do notebook com Jupyter. O treino precisa de GPU CUDA. Para gerar slides também são necessários LibreOffice e pdftoppm.

Os comandos podem substituir dados e resultados. Uma cópia de trabalho preserva os arquivos existentes.

A leitura completa, os diagramas e o glossário estão nos arquivos Markdown deste pacote.

Os resultados valem para as duas taxas, a semente e o conjunto de teste registrados. Não demonstram uma regra geral.
